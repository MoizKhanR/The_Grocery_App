# 🛒 The Grocery App

A cross-platform mobile application for iOS and Android built with **.NET MAUI** and **C#**, designed to simplify grocery shopping and catalog management.

## 📱 About

The Grocery App is a personal project demonstrating cross-platform mobile development using Microsoft's .NET MAUI framework. The app manages a comprehensive grocery catalog with intelligent categorization and an intuitive shopping list experience.

## ✨ Features

- 🗂️ **1,400+ grocery items** organized across **22 categories**
- 🛍️ **Shopping list management** — add, remove, and track items
- 📂 **Category-based browsing** — easily navigate items by category
- 🔍 **Search functionality** — quickly find items across the catalog
- 📱 **Cross-platform** — runs on both iOS and Android from a single codebase
- ⚡ **Fast and responsive UI** built with XAML and MVVM architecture

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| .NET MAUI | Cross-platform mobile framework |
| C# | Primary programming language |
| XAML | UI markup language |
| MVVM | Architectural pattern |

## 🚀 Getting Started

### Prerequisites
- Visual Studio 2022 or later
- .NET 8 SDK or later
- .NET MAUI workload installed

### Running the App
1. Clone the repository
2. Open `The_Grocery_App.slnx` in Visual Studio
3. Select your target platform (iOS/Android)
4. Build and run
